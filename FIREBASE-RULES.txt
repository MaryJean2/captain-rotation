Paste these into Firebase Console > Firestore Database > Rules, then click Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rotationPlanner/{document=**} {
      allow read, write: if request.auth != null;
    }
    match /chiefStewardessRotation/{document=**} {
      allow read, write: if request.auth != null;
    }
    match /captainsRotation/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

This keeps Chief Officer, Chief Stewardess and Captains planner data in separate Firestore paths.
Only signed-in Firebase Authentication users can read or edit the planners.
